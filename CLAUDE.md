# Working agreement

## Game design decisions belong to the user

- Work step by step. Do not run ahead and implement a whole design on your own.
- Before adding or changing any game design element (mechanics, rules, cards,
  enemies, progression, balance numbers, UI/flow, art direction, naming),
  propose the options briefly and wait for the user's decision.
- Keep each step small and focused on what the user asked for; ask before
  expanding scope.
- Purely technical work (fixing bugs, tests, refactors that don't change
  gameplay) can proceed, but say what you're doing.
